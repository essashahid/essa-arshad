## The problem

Pulling terms out of contracts by hand is slow. And an extracted value nobody can trace back to the page is hard to trust. {/* TEMP */}

## What I built

1. Parse each PDF page by page {/* TEMP */}
2. Extract fields with a page reference on each one {/* TEMP */}
3. Flag uncertain fields for a person to review {/* TEMP */}

## Why these settings

**Page reference on every field.** A reviewer can jump to the source in one click. {/* TEMP */}
